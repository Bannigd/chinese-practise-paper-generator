# Генератор китайской клетки

Простой офлайн-генератор прописей для китайских иероглифов: ми-цзы-ге (米字格),
тянь-цзы-ге (田字格) или пустая сетка. Один HTML-файл, без зависимостей и интернета.

## Как пользоваться

1. Откройте `index.html` в браузере (Chrome, Edge, Firefox).
2. Настройте клетку, отступы и внутренние линии — превью обновляется сразу.
3. Нажмите **«Печать / PDF»**.
4. В диалоге печати выберите **«Сохранить как PDF»**:
   - поля — «Нет»;
   - масштаб — 100% (или «По размеру страницы»);
   - включите печать фона, если браузер её отключает.

Кнопка **«Скачать SVG»** сохраняет векторный шаблон — его можно открыть в
Illustrator/Figma/Inkscape или распечатать позже.

## Масштаб предпросмотра

В правом верхнем углу есть кнопки **− / +**, процент масштаба и кнопка **«Вписать»**.
Процент показывает масштаб относительно физического размера листа: 100% — лист
на экране в натуральную величину (по CSS-миллиметрам), 50% — вдвое меньше.
При загрузке лист автоматически вписывается в окно, поэтому процент обычно
меньше 100%; кнопка **«Вписать»** возвращает этот режим.

Масштаб меняется также через Ctrl + колесо мыши над предпросмотром (или pinch
на трекпаде) в диапазоне 10–400%. Это влияет только на просмотр: размер листа
и PDF при печати не меняются.

Под заголовком панели настроек показаны две сводки: **«Клеток»** — сколько
клеток помещается по ширине и высоте, и **«Лист»** — текущий формат.

## Что можно настроить

| Параметр | Значения |
| --- | --- |
| Размер клетки | 5–40 мм |
| Отступ от краёв | 0–40 мм |
| Внутренние линии | ми-цзы-ге, тянь-цзы-ге, только диагонали, без линий |
| Стиль внутренних линий | пунктир или сплошные |
| Толщина основных линий | 0.05–1 мм |
| Непрозрачность основных линий | 10–100% |
| Толщина дополнительных линий | 0.05–0.8 мм |
| Непрозрачность дополнительных линий | 10–100% |
| Шапка | «Имя / Дата» вкл/выкл |
| Формат | A4, A5, Letter (215.9 × 279.4 мм) |
| Цвет | любой цвет основных линий; направляющие и линии шапки — осветлённый вариант |

Сетка автоматически вписывается в лист: количество клеток зависит от их размера,
отступов и наличия шапки. Если после подбора остаётся место, сетка центрируется.
При отступе 0 мм принтер может обрезать крайние линии — это ограничение самого
принтера, а не шаблона.

Пунктирные направляющие построены так, чтобы в центре клетки и на стыках линии
сходились симметрично при любом размере клетки: длина штриха фиксирована, а
количество штрихов подстраивается под размер клетки. В центре проходит только
диагональный крест, а у горизонтально-вертикального креста сделан пропуск —
как в образце.

## Готовый пример

`example-16mm-a4.pdf` — лист A4 с клеткой 16 мм, отступом 14 мм и ми-цзы-ге,
сгенерированный со стандартными настройками.

## Генерация PDF из командной строки

Параметры можно передать через URL, например:

```text
index.html?cell=16&margin=14&guides=mizige&format=a4&header=1
```

Доступные значения `guides`: `mizige`, `tianzige`, `diagonals`, `none`.
`format`: `a4`, `a5`, `letter`. Флаги `header` и `dashed`: `1`/`0`
(также принимаются `true`/`false`). Толщина и непрозрачность задаются
параметрами `mainWidth`, `mainOpacity`, `guideWidth`, `guideOpacity`
(например, `mainWidth=0.4&mainOpacity=70`). Цвет — `color=%23RRGGBB`
(решётку в URL нужно кодировать как `%23`). Параметр `zoom` задаёт масштаб
предпросмотра от `0.1` до `4` (на печать не влияет). Внешний контур сетки
автоматически в 1.8 раза толще основных линий.

Chrome/Chromium умеет сразу сохранить такой лист в PDF:

```bash
google-chrome --headless --no-pdf-header-footer \
  --print-to-pdf=chinese-grid.pdf \
  "file:///полный/путь/index.html?cell=16&margin=14&guides=mizige&format=a4"
```
